# BigBook For All

A cross-platform app that uses AI to adapt the Alcoholics Anonymous Big Book for different recovery paths and readers.

## What it does
- Adapts the text for different addictions: alcohol, drugs, gambling, food, codependency, and more
- Language options: original, gender-neutral, female-focused, male-focused
- No login, no accounts, no tracking — preferences stay on your device
- Offline-first: adapted chapters are cached for reading anywhere
- Chapter navigation with reading progress

## Built with
React Native · Expo · TypeScript · AI text transformation
